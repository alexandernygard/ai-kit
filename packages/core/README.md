# @alexandernygard/ai-kit

The ai-kit runtime: agents, tools, sessions with branches and forks, approvals, permissions, hooks, skills, tool search, code mode, subagents, compaction, plugins and stores. No dependencies; runs in Node, browsers, Workers, Deno and Bun.

```bash
pnpm add @alexandernygard/ai-kit
```
