# @alexandernygard/ai-kit-claude-agent

Harness driver for the Claude Agent SDK. Runs ai-kit agents on Claude Code with your Claude subscription or an API key; ai-kit tools are bridged over in-process MCP.

```bash
pnpm add @alexandernygard/ai-kit-claude-agent @anthropic-ai/claude-agent-sdk
```
