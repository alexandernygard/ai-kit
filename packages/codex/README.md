# @alexandernygard/ai-kit-codex

Harness driver for the OpenAI Codex SDK. Runs ai-kit agents on Codex with your ChatGPT subscription or an API key; ai-kit tools are bridged over a per-run localhost MCP endpoint.

```bash
pnpm add @alexandernygard/ai-kit-codex @openai/codex-sdk
```
