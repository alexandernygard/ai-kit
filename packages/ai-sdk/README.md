# @alexandernygard/ai-kit-ai-sdk

Model driver for any AI SDK language model, with prompt caching on Anthropic, effort, provider tools and structured output. For Claude, `@alexandernygard/ai-kit-anthropic` calls the API directly.

```bash
pnpm add @alexandernygard/ai-kit-ai-sdk ai @ai-sdk/openai
```
